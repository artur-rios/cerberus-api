# Public test data attribution

These values are public tests, never production keys. Published expected values
are selections from RFC 5869 (2010), RFC 6979 (2013), RFC 7638 (2015), RFC 9106
(2021), the CFRG HPKE vector corpus, and NIST CAVS 14.0 GCM vectors (2012).
`sources.json` preserves exact download URLs, revisions, hashes and license links.
There is no IETF, NIST or third-party security certification of this harness.
